---

사용자가 지정한 문서 출력 폴더를 검색한다. 로컬에 IndexRay MCP가 연결되어 있으면 검색 결과에서 필요한 본문만 읽는다. 클라우드에서는 접근 가능한 Markdown 파일을 직접 읽는다.

“지난주” 등의 기간은 사용자의 현지 날짜로 해석한다. 제목·참석자·안건으로 후보를 좁히고 본문에서 회의일을 확인한다. modified_at은 파일 수정 시각이다. 회의일을 확인할 수 없는 자료는 구분한다.

결정사항과 논의 중인 의견을 구별한다. 담당자와 기한은 본문에 명시된 경우에 적는다. 각 결과에 source_root와 source_path, 가능하면 시트명이나 슬라이드 번호를 붙인다. 클라우드에서 읽은 파일에 링크할 수 있으면 해당 Markdown 링크도 제공한다.
